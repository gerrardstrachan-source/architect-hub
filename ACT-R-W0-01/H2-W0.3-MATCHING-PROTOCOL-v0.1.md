# H2 — Immediate-Performance Matching Protocol v0.1

## Status
**PROTOCOL v0.1 — PRE-MODEL / PRE-OBSERVATION**

This protocol defines immediate-performance matching before any ACT-R training result is inspected. It does not authorize H2 empirical execution.

## 1. Fixed histories

H-S: `A0 iff x XOR y = 1`

H-C: `A0 iff c XOR x = 1`

Active v0.3 training states are `000, 001, 011, 100, 110, 111`, each 32 times, for 192 trials. The ordered observable stimulus sequence is identical across histories. Training action marginals are identical at 64 A0 / 128 A1.

## 2. No-selection rule

No seed, history realization, parameter setting, or model candidate may be selected because it produces a favorable match. All declared primary and replication seeds are retained. Tolerances may not be widened after results are observed.

## 3. Seed sets

Primary seed set: minimum 32 seeds.

Independent replication seed set: minimum 32 seeds.

The same seed is paired across H-S and H-C. Exact seed identities are fixed before matching execution.

## 4. Matching variables and tolerances

### Accuracy

Full-training accuracy and terminal 32-trial accuracy must differ by no more than 0.05 in absolute proportion.

### Trials-to-criterion

Criterion is the first trial `t >= 20` for which the preceding 20 completed trials contain at least 18 correct responses.

If both histories reach criterion, absolute TTC difference must be at most 20 trials.

If both histories are `NO-CRITERION`, the TTC component is treated as categorical agreement and contributes a pass; no numerical TTC difference is computed for that pair.

If exactly one history reaches criterion, the TTC component fails for that paired seed.

### Response latency

Median action-selection latency across the 192 completed training trials is used only when the final ACT-R timing architecture defines a valid observable latency.

The admissible ratio is:

`0.90 <= medianRT(H-S) / medianRT(H-C) <= 1.10`

Latency therefore remains conditionally operational until the final ACT-R model specification locks the timing architecture.

## 5. Distributional decision

For each paired seed, calculate accuracy differences, applicable TTC differences, and latency ratios.

At least 90% of paired seeds must satisfy each applicable tolerance, and the corresponding median paired statistic must also lie within the tolerance.

No seed is removed because of an unfavorable numerical result.

## 6. Primary and replication passes

The primary seed set passes only when every applicable matching component passes under the rules above.

The independent replication seed set is evaluated under the identical locked rules.

Overall matching is **CONFIRMED** only when both primary and replication sets pass.

## 7. Technical failure rule

A corrupted, incomplete, or technically invalid run is not counted as a poor-performing seed. The same declared seed must be rerun after the technical defect is corrected. Numerical inconvenience is never a reason for exclusion.

## 8. No-match rule

If either seed set fails matching, H2 does not proceed to future-learning comparison in its current form.

No post-hoc tolerance changes, seed selection, history substitution, parameter tuning for matching, criterion changes, or favorable-run filtering are permitted.

## 9. Interpretation boundary

A successful match establishes only comparable observable immediate performance under the frozen ACT-R realization and declared seed distributions. It does not establish equal internal state, equal representation, relational abstraction, or understanding.

## 10. Pre-observation lock

The protocol is immutable after the first matching result is inspected. Seed sets, tolerances, criterion, rejection policy, and model-selection policy may not be rewritten using observed matching outcomes.
