## Decision
The v0.1 A-condition is superseded. The repaired v0.2 world changes A from a reordered replay into a held-out-conjunction extension while preserving binary `c,x,y` and the two-action interface.

## Formal training world
State space:
`(c,x,y) in {0,1}^3`.

Training presents exactly six states, each 32 times (192 trials total):
`000, 010, 011, 101, 110, 111`.

The two states:
`001` and `100`
are completely absent from training.

The same ordered observable input sequence is used for H-S and H-C.

### H-S
`A0 iff x XOR y = 1`.

### H-C
`A0 iff c XOR x = 1`.

Both training contingencies have 96 A0 and 96 A1 world-level correct actions. The observable input order is identical across histories, while 64 of the 192 feedback labels differ. H-C is therefore not a no-structure control.

## A-condition novelty proof

A presents the full binary state space in the frozen future order, 12 times per state (96 trials).

The novelty is mechanical:

1. `001` and `100` occur zero times in either training fixture.
2. Every primitive value `c=0/1`, `x=0/1`, `y=0/1` has already occurred during training.
3. Therefore novelty is neither a new primitive symbol nor a mere display reordering.
4. The genuinely new learner-accessible objects are the joint conjunctions `(c,x,y)=001` and `100`.
5. A uses the unchanged source relation for those states.
6. The experimenter cannot identify A's novelty merely by naming it; the absence/presence is checkable directly from the ordered fixtures.

Thus A is a **held-out recombinative extension** of the experienced task family.

## B
B preserves the exact future source-state order and changes only the target contingency to:
`A0 iff c XOR y = 1`.

The relation uses the same primitive variables and response vocabulary while changing the feature-role relationship.

## C
C applies the fixed bijection:
`c' = 1-c`, `x' = 1-x`, `y' = 1-y`.

Both source parity relations are invariant under the corresponding paired inversions:
`x' XOR y' = x XOR y`
and
`c' XOR x' = c XOR x`.

No relation label or inverse-decoding instruction is presented to the learner.

## D
D preserves the source input order and primitive vocabulary while complementing the source correct action:
`A0 <-> A1`.

### Accessibility — PASS

### Reproducibility — PASS

### Neutrality — PASS AT WORLD LEVEL
