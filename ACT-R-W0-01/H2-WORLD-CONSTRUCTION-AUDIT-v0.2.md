# H2 World Construction Audit v0.2

## Decision
The v0.1 A-condition is superseded. The repaired v0.2 world changes A from a reordered replay into a held-out-conjunction extension while preserving binary `c,x,y` and the two-action interface.

## Formal training world
State space:
`(c,x,y) in {0,1}^3`.

Training presents exactly six states, each 32 times (192 trials total):
`000, 010, 011, 101, 110, 111`.

The two states:
`001` and `100`
are completely absent from training.

The same ordered observable input sequence is used for H-S and H-C.

### H-S
`A0 iff x XOR y = 1`.

### H-C
`A0 iff c XOR x = 1`.

Both training contingencies have 96 A0 and 96 A1 world-level correct actions. The observable input order is identical across histories, while 64 of the 192 feedback labels differ. H-C is therefore not a no-structure control.

## A-condition novelty proof

A presents the full binary state space in the fixed future order, 12 times per state (96 trials).

The novelty is mechanical:

1. `001` and `100` occur zero times in either training fixture.
2. Every primitive value `c=0/1`, `x=0/1`, `y=0/1` has already occurred during training.
3. Therefore novelty is neither a new primitive symbol nor a mere display reordering.
4. The genuinely new learner-accessible objects are the joint conjunctions `(c,x,y)=001` and `100`.
5. A uses the unchanged source relation for those states.
6. The experimenter cannot identify A's novelty merely by naming it; the absence/presence is checkable directly from the ordered sequences.

Thus A is a **held-out recombinative extension** of the experienced task family.

## B
B preserves the exact future source-state order and changes the target contingency to:
`A0 iff c XOR y = 1`.

The relation uses the same primitive variables and response vocabulary while changing the feature-role relationship.

## C
C applies the fixed bijection:
`c' = 1-c`, `x' = 1-x`, `y' = 1-y`.

Both source parity relations are invariant under the corresponding paired inversions:
`x' XOR y' = x XOR y`
and
`c' XOR x' = c XOR x`.

No relation label or inverse-decoding instruction is presented to the learner.

## D
D preserves the source input order and primitive vocabulary while complementing the source correct action:
`A0 <-> A1`.

## Adversarial gate results

### Identity — PASS AT WORLD-CONSTRUCTION LEVEL
The state space, ordered training sequences, ordered future sequences, contingency rules, counts, and sequence hashes are explicitly specified. The complete ordered state sequences are materialized in `ACT-R-W0-01/H2-W0.2-STATE-SEQUENCES.json`.

### Isolation — PASS WITH DEFINED SCOPE
A differs from training by the first appearance of exactly two joint states, while retaining the source relation. B/C/D operate on the same future source-state schedule; only their declared transformations alter the contingency or presentation mapping.

### Accessibility — PASS
The learner-facing stimulus fields remain only `c,x,y`; action set is `{A0,A1}`. Correct-action labels are environmental ground truth, not a learner input before choice.

### Reproducibility — PASS
Training and future sequences are deterministic from declared seeds and are also explicitly materialized. The ordered-state artifact records per-fixture sequence hashes.

### Neutrality — PASS AT WORLD LEVEL
The world specifies environmental contingencies but does not encode a learner-side representation such as `XOR`, relation labels, or structural chunks.

### H-S/H-C interpretation — LOCKED
The scientific contrast is:
> Does learning one observable relational contingency alter future-learning consequences relative to learning a matched-complexity alternative relational contingency?

It is not:
> structure versus no structure.

### Materialization integrity — PASS AFTER SAFEGUARD
An attempted direct CSV transfer was found not to match the locally generated byte sequence. It was deleted before being used as evidence. The final committed artifact uses compact exact ordered state sequences with independently recorded sequence hashes.

### Immediate-performance matching — NOT TESTED
World symmetry does not establish ACT-R matching. Any matching criterion remains an empirical/model-level gate and cannot be created post hoc.
